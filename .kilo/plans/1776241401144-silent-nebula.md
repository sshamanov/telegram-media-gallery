# Plan: Allow silent status ledger edits

## Goal
Configure Kilo so both PLAN and CODE flows can modify `.kilo/status.md` without interactive permission prompts.

## Current findings
- Project config is in `kilo.jsonc`, not `kilo.json`.
- The current top-level permission block already allows broad markdown edits via `"*.md": "allow"` and `.kilo/**` via `"allow"`.
- PLAN and CODE agents are configured in `kilo.jsonc` under `agent.plan` and `agent.code`, but neither has an explicit agent-level `permission` override.
- Existing subagent files in `.kilo/agent/` do not define permission blocks.

## Likely root cause
- The prompt is likely coming from agent-level permission defaults or mode-specific behavior rather than the repo-wide `permission.edit` glob, so the safest fix is to add explicit `permission.edit` rules for both `code` and `plan` agents that allow `.kilo/status.md`.

## Recommended implementation
1. Update `kilo.jsonc`.
2. Add explicit per-agent permission blocks for both `agent.code` and `agent.plan`:
   - `"permission": { "edit": { ".kilo/status.md": "allow" } }`
3. Keep the existing top-level `permission` block unchanged unless broader silent-edit behavior is also desired.
4. If Kilo evaluates first-match top-to-bottom within the same permission object, place the specific `.kilo/status.md` allow rule before broader fallback rules if any are later added.

## Optional stronger variant
- If the user wants all agents/modes to edit the ledger without prompts, add the same explicit rule at the top-level `permission.edit` block too:
  - `".kilo/status.md": "allow"`
- This is broader than requested; recommended only if the user wants consistent silent ledger updates across every mode and subagent.

## Example config shape
```jsonc
{
  "agent": {
    "code": {
      "model": "deepseek/deepseek-chat",
      "temperature": 0.1,
      "permission": {
        "edit": {
          ".kilo/status.md": "allow"
        }
      }
    },
    "plan": {
      "model": "openai/gpt-5.4",
      "variant": "medium",
      "temperature": 0.1,
      "permission": {
        "edit": {
          ".kilo/status.md": "allow"
        }
      }
    }
  }
}
```

## Notes
- This change belongs in project config `kilo.jsonc` because the request is project-specific.
- No AGENTS.md change is required for the permission itself.
- A restart/reload of the Kilo session may be needed for config changes to take effect.
