# Pull‑to‑Refresh Implementation

**Goal:** Implement pull‑to‑refresh gesture for the gallery screen, allowing users to refresh media content by pulling down on touch devices and providing a visual feedback indicator.

## Overview

The gallery currently requires users to manually trigger a refresh through indirect means (navigating away and back, or using browser refresh). Pull‑to‑refresh is a standard mobile UX pattern that improves usability on touch devices.

This feature will:
1. Detect pull‑down gestures on touch devices
2. Show visual feedback (progress indicator)
3. Trigger media refresh when threshold is reached
4. Work seamlessly with existing gallery loading state
5. Respect offline state (disable when offline)

## Technical Considerations

### Touch Event Handling
```typescript
// Basic approach
let startY = 0
let currentY = 0

function onTouchStart(e: TouchEvent) {
  if (window.scrollY === 0) { // Only at top
    startY = e.touches[0].clientY
  }
}

function onTouchMove(e: TouchEvent) {
  if (startY === 0) return
  
  currentY = e.touches[0].clientY
  const distance = currentY - startY
  
  if (distance > 0) { // Pulling down
    e.preventDefault()
    updatePullProgress(distance)
  }
}
```

### Visual Feedback Options
1. **Simple spinner**: Show when pulling, rotate based on distance
2. **Progress bar**: Fill as user pulls down
3. **Text indicator**: "Pull to refresh" → "Release to refresh" → "Refreshing..."
