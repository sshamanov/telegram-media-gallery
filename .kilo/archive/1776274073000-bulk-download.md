## Technical Details

### Download Queue State Structure
```typescript
interface DownloadQueueItem {
  id: string; // media item id
  fileName: string;
  progress: number; // 0-100
  status: 'queued' | 'downloading' | 'complete' | 'error' | 'cancelled';
  error: string | null;
}

interface DownloadQueueState {
  active: boolean;
  currentIndex: number;
  items: DownloadQueueItem[];
  totalItems: number;
  completedItems: number;
}
```

### Chained Download Algorithm
1. For each selected media item:
   - Update status to 'downloading'
   - Call `getCachedOrDownloadBlob(item, 'full', { onProgress })`
   - On progress update: update item progress
   - On completion: call `saveBlob(blob, item.filename)`
   - Update status to 'complete'
   - Move to next item
2. Handle errors: mark item as 'error', continue with next
3. Support cancellation via abort signal

### UI Integration Points
- Selection header: "Download" button (enabled when items selected)
- Download panel: shows when `downloadQueueState.active` is true
- Progress indicators: item progress + overall progress
- Cancel button: stops current and queued downloads

## Risks and Mitigations
- Risk: Browser may block multiple simultaneous downloads
  - Mitigation: Sequential downloads with small delay between
- Risk: Large downloads may timeout
  - Mitigation: Implement abort signals and timeouts
- Risk: Memory issues with many large files
  - Mitigation: Process one at a time, release blobs after saving
