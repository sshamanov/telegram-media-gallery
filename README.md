# Telegram Gallery

Web-based image gallery using Telegram as storage.

## Setup

1. Get API credentials from https://my.telegram.org/apps
   - Create a new application
   - Note your `api_id` and `api_hash`

2. Install dependencies:
```bash
npm install
```

3. Run development server:
```bash
npm run dev
```

4. Open browser and enter your Telegram API credentials

## Features

- Connect to Telegram account
- Browse groups/channels
- View photos in grid
- Fullscreen viewer with keyboard navigation
- High quality images (2560x2560)
- Session stored in browser

## Usage

- Click on a group to view photos
- Click on photo for fullscreen view
- Use arrow keys or buttons to navigate
- Press ESC to close fullscreen
